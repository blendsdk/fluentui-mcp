## Feature Overview

This requirement defines how the skill reaches a user's machine. The skill is published as the npm
package `fluentui-skill` and installed into one or more coding agents with a CLI command,
`fluentui skill install`. The installer detects supported clients, copies (or links) the skill into
their skill directories, records a version marker, and supports status and uninstall.

The package ships the prebuilt skill only; the enhanced JSON is not published, because the skill is
consumed as Markdown, not regenerated by end users.

## Functional Requirements

### Must Have

- [ ] The npm package is named `fluentui-skill` and exposes a `fluentui` bin.
- [ ] `fluentui skill install` installs the skill; `fluentui skill status` reports the installed
      version; `fluentui skill uninstall` removes it.
- [ ] Supported clients and paths:

  | Client | Global | Project |
  |--------|--------|---------|
  | OpenCode | `~/.config/opencode/skills` | `.opencode/skills` |
  | Claude Code | `~/.claude/skills` | `.claude/skills` |
  | Codex | `~/.codex/skills` | `.codex/skills` |
  | Shared `.agents` | `~/.agents/skills` | `.agents/skills` |

- [ ] Flags: `--all` (every detected client), `--target <dir>` (repeatable), `--project` (project
      directories), `--link` (symlink instead of copy), `--dry-run` (report only).
- [ ] Installation replaces only the `fluentui/` directory and never touches other skills.
- [ ] A marker file `.fluentui-skill.json` records `{ version, source, installedAt }`.
- [ ] Installation is atomic: copy to a temporary sibling, then rename over the destination, with
      recovery from leftovers after an interrupted run.
- [ ] An `assemble` build step copies `.agents/skills/fluentui/` to the packaged
      `skills/fluentui/`.
- [ ] `package.json` `files` publishes `dist/`, `skills/`, `README.md`, and `LICENSE`; it does not
      publish `data/`.

### Should Have

- [ ] `fluentui skill install --dry-run` prints the resolved destinations without writing.
- [ ] `status` exits non-zero when the skill is not installed.
- [ ] A post-install hint names the client directories used.

### Won't Have (Out of Scope)

- Publishing `data/` or the pipeline to npm — AR-14.
- Auto-editing any agent configuration file (MCP-style config is gone).
- A hosted registry or download service.
- Symlinks across filesystems on Windows (copy is the default).

## Technical Requirements

### CLI surface

```
fluentui skill install   [--all | --target DIR | --project] [--link] [--dry-run]
fluentui skill status    [--all | --target DIR | --project]
fluentui skill uninstall [--all | --target DIR | --project] [--dry-run]
```

### Client detection

A client is detected when its global directory, its parent, or its project directory exists. With
no selection flag, the installer prompts for detected clients; `--target` overrides detection.

### Packaging

| File | Purpose |
|------|---------|
| `dist/` | Compiled bin and installer |
| `skills/fluentui/` | Assembled skill tree |
| `README.md`, `LICENSE` | Package metadata |

A `prepack`/`prepublishOnly` script runs build, assemble, tests, and gates so a broken skill cannot
be published.

### Version reporting

The installed version comes from the package's `package.json` and is written into the marker.

## Integration Points

### With RD-03

The installer copies the generator's output; `assemble` is the bridge between the source tree and
the published tree.

### With RD-04

The publish path runs the freshness and example gates before packaging.

### With RD-06

Once the installer works, the MCP runtime and its configuration instructions are removed.

## Scope Decisions

| Decision | Options Considered | Chosen | Rationale | AR Ref |
|----------|-------------------|--------|-----------|--------|
| Distribution | npm + installer / repo only / both | npm package + `skill install` CLI | Proven blendsdk pattern; multi-client | AR-07 |
| Name | `fluentui-skill`+`fluentui` / `fluentui-mcp` | `fluentui-skill`, bin `fluentui` | Honest name after MCP removal | AR-13 |
| Ship data | No / yes | Do not ship `data/` | Smaller package; skill is prebuilt | AR-14 |
| Install safety | Overwrite in place / atomic temp + rename | Atomic temp + rename with recovery | Never leaves a partial skill | AR-07 |
| Link option | Copy only / copy + symlink | Both, copy default | Developer convenience | AR-07 |

## Security Considerations

> **🚨 Mandatory.** The installer writes outside the repository into user home directories.

- **Data sensitivity**: none stored; the marker holds only a version.
- **Input validation**: every `--target` path is resolved and used only as a directory; `..`
  traversal is not followed beyond the user's chosen path.
- **Authentication & authorization**: N/A.
- **Injection risks**: no shell execution; filesystem APIs only.
- **Encryption needs**: npm transport uses HTTPS/TLS.
- **Rate limiting**: N/A.
- **Infrastructure**: none.

## Acceptance Criteria

1. [ ] `npm pack --dry-run` lists `skills/fluentui/SKILL.md` and `dist/` but no `data/` path.
2. [ ] `fluentui skill install --target <tmp>` creates `<tmp>/fluentui/SKILL.md` and
       `<tmp>/fluentui/.fluentui-skill.json` whose `version` equals the package version.
3. [ ] `fluentui skill status --target <tmp>` prints the installed version and exits 0; against an
       empty directory it exits non-zero.
4. [ ] `fluentui skill uninstall --target <tmp>` removes only the `fluentui/` directory and leaves
       any sibling skill untouched.
5. [ ] An interrupted install (simulated by a leftover temp directory) is cleaned up and re-install
       succeeds.
6. [ ] `--dry-run` writes nothing and prints every resolved destination.
7. [ ] Security requirements verified: a `--target` containing `..` is resolved safely and never
       causes writes outside the resolved directory.
