# Skill Generator: FluentUI Agent Skill

> **Document**: 03-02-skill-generator.md
> **Parent**: [Index](00-index.md)
> **Implements**: RD-03

## Overview

This specification defines the deterministic generator that turns
`data/v9/fluentui-schema-enhanced.json` into the `fluentui` Agent Skill tree under
`.agents/skills/fluentui/`. No LLM runs here; the hand-written `SKILL.md` and templates are never
generated.

## Architecture

### Current Architecture

Runtime formatters (`src/formatters/*`) render schema entries to Markdown per MCP tool call. They
are stateful to the server but individually stateless functions.

### Proposed Changes

- Relocate the reusable renderers to `scripts/skill/render/` (PR-5); delete the originals with the MCP runtime.
- Add `scripts/skill/generate.ts`, `mapping.ts`, and `manifest.ts`.
- Hand-write `SKILL.md` and `assets/templates/*`.

## Implementation Details

### Skill tree

```
.agents/skills/fluentui/
├── SKILL.md                         # hand-written
├── assets/templates/*.md            # hand-written
└── references/
    ├── index.md
    ├── foundation/<id>.md
    ├── components/<id>.md
    ├── categories/<category>.md
    ├── recipes/<group>/<id>.md
    └── quick-reference/<id>.md
```

### `SKILL.md` frontmatter

```yaml
---
name: fluentui
description: Use when building React user interfaces with FluentUI React v9 (for example Button, Input, Dialog, DataGrid, FluentProvider, makeStyles, tokens). Covers setup, theming, styling, accessibility, component APIs, and task recipes, with verified examples from the real package.
license: MIT
compatibility: FluentUI React v9 with React 17/18; examples import from @fluentui/react-components and @fluentui/react-icons.
metadata:
  author: blendsdk
---
```

The body carries hard rules (import from `@fluentui/react-components`/`@fluentui/react-icons`;
never invent props; check the installed version first; prefer the verified examples), a task
routing table, a component/category map, and a pointer to `references/index.md`. Body ≤ 500 lines.

### Determinism contract

| Rule | Detail |
| ---- | ------ |
| Ordering | ids alphabetical; recipe groups in fixed order |
| Encoding | UTF-8, LF only; `\r\n` normalized |
| Timestamps | none in generated files |
| Atomicity | build in memory; write only after validation |
| Marker | `<!-- Generated by scripts/skill/generate.ts — do not edit by hand. -->` |
| Mapping | explicit table in `mapping.ts` |

### Component rendering

| Section | Source |
| ------- | ------ |
| Header | name, package, import, category, stability, deprecation |
| Overview | `enhanced.description` + `whenToUse`; fallback to a neutral line |
| Props | `props[]` — name, type, default, required, description |
| Slots | `slots[]` — name, element type, required, description |
| Examples | up to three `stories[].code` in `tsx` fences |
| Guidance | best practices, prop guidance, anti-patterns (prose), accessibility, styling, performance, theming, edge cases |
| Links | related recipes and its category file |

Sections render only when their data exists. Markdown-special characters in values are escaped.

### Manifest

`.fluentui-skill-manifest.json` records `{ schemaHash, generatorVersion, generatedAt, files: { path: hash } }`.

### Rendering helpers

`render/props.ts`, `render/stories.ts`, `render/sections.ts` — pure functions returning strings.
No class instances; consistent with the existing functional style.

## Integration Points

- Input is the enhanced schema (03-01); output is consumed by gates (03-03) and packaging (03-04).
- `--check` mode regenerates into a temp directory for the drift gate.

## Error Handling

| Error Case | Handling Strategy | AR Ref |
| ---------- | ----------------- | ------ |
| Schema missing/malformed | Exit non-zero; write nothing | AR-05 |
| Schema id unsafe for a path | Reject before write | AR-06 |
| Missing `SKILL.md` | Fail the run | AR-05 |
| Unknown recipe group | Fail with the group name | AR-17 |

## Testing Requirements

- Determinism test: two runs byte-identical.
- Coverage test: file set matches mapping counts.
- Rendering tests per section; escaping test.
- Error tests: malformed schema, unsafe id, missing `SKILL.md`.
